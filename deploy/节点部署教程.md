# Tunnel 节点部署教程

## 准备工作

1. 一台 Linux VPS（Ubuntu/Debian），root 权限
2. 一个域名，A 记录解析到 VPS IP
3. 本项目代码（已编译好 server 二进制）

## 方法一：一键脚本部署（推荐）

### 前置：安装 paramiko
```
pip install paramiko
```

### 编译服务端（如果没有）
```powershell
# arm64 VPS (Oracle、AWS Graviton 等)
$env:GOOS='linux'; $env:GOARCH='arm64'; go build -o server-linux-arm64 ./cmd/server/

# amd64 VPS (大部分云厂商)
$env:GOOS='linux'; $env:GOARCH='amd64'; go build -o server-linux-amd64 ./cmd/server/
```

### 运行部署脚本
```
python deploy/deploy_node.py <VPS_IP> <SSH密码> <域名>
```

示例：
```
python deploy/deploy_node.py 45.67.89.10 MyPass123 us.mysite.com
```

脚本会自动：安装 Caddy → 上传二进制 → 配置 systemd → 申请 SSL 证书 → 启动服务

部署完成后，把打印出来的节点信息添加到后台管理面板即可。

## 方法二：手动部署（5 步）

### 1. 上传二进制

```bash
# 在 VPS 上
mkdir -p /opt/tunnel /var/www/html
```

把编译好的 `server-linux-arm64`（或 amd64）上传到 `/opt/tunnel/tunnel-server`：
```bash
chmod +x /opt/tunnel/tunnel-server
```

### 2. 写配置

```bash
cat > /opt/tunnel/server.json << 'EOF'
{
    "listen": "127.0.0.1:8080",
    "psk": "这里换成你的随机密钥",
    "web_root": "/var/www/html"
}
EOF
```

生成随机 PSK：
```bash
openssl rand -base64 24
```

### 3. 创建 systemd 服务

```bash
cat > /etc/systemd/system/tunnel.service << 'EOF'
[Unit]
Description=Tunnel Server
After=network.target

[Service]
ExecStart=/opt/tunnel/tunnel-server -c /opt/tunnel/server.json
WorkingDirectory=/opt/tunnel
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable tunnel
systemctl start tunnel
```

### 4. 安装 Caddy（自动 HTTPS）

```bash
apt install -y debian-keyring debian-archive-keyring apt-transport-https curl
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | tee /etc/apt/sources.list.d/caddy-stable.list
apt update
apt install -y caddy
```

配置 Caddy（把 `your.domain.com` 换成你的域名）：
```bash
cat > /etc/caddy/Caddyfile << 'EOF'
{
	servers {
		protocols h1
	}
}

your.domain.com {
    handle {
        reverse_proxy 127.0.0.1:8080
    }
}
EOF

systemctl restart caddy
```

### 5. 在后台添加节点

打开管理后台 → 节点 tab → 添加节点：

| 字段 | 填写 |
|------|------|
| 名称 | 自定义，如"美国节点" |
| 域名 | your.domain.com |
| IP   | VPS 的 IP（可选） |
| PSK  | server.json 里的 psk |
| 地区 | 自定义，如"美国" |

添加后客户端会自动获取新节点。

## 检查状态

```bash
systemctl status tunnel     # 查看 tunnel 服务
systemctl status caddy      # 查看 Caddy
journalctl -u tunnel -f     # 实时日志
```

## 常见问题

**证书申请失败**: 确认域名 A 记录已解析到 VPS IP，且 80/443 端口未被占用

**连接超时**: 检查防火墙，需放行 80 和 443 端口：
```bash
ufw allow 80
ufw allow 443
```
