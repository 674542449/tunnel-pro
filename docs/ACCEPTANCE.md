## 本地验证

最终 `tools/build.ps1` 的全包测试、`go vet` 和全包 `go test -race -tags=http2legacy` 均通过。主要覆盖：

- H3/H2 × 普通/严格模式；TLS 身份验证、ECH 成功及拒绝，不向普通模式降级。
- 错误或重复 Token、错误协议版本、无效 UDP URI、无效端口、HTTP/1 CONNECT 均不触发目标解析/连接。
- TCP 下载完整性、上传 FIN 后仍可读取返回、16 个并发流、SOCKS/HTTP 应用代理。
- 原生/Capsule UDP、SOCKS UDP ASSOCIATE、FRAG 拒绝、IPv6 TCP/UDP 目标。
- 截断、超长 Capsule、无效 Context ID、未知扩展处理。
- QPACK 凭据 never-index；严格配置不能缺少 ECH、回环监听限制、未知配置字段拒绝。
- 控制接口 Host/Origin/CSRF 检查及状态不泄露 Token。
- 隔离注册表测试中的代理启用、恢复、PAC 保存、崩溃恢复及外部改动保护；未为验收修改用户实际系统代理。

本地控制页面没有进行浏览器渲染验收。浏览器访问本地地址被权限审核拒绝；接口测试和实际 EXE 测试均在不打开浏览器的条件下进行。

## 单线路性能观测

下载为每项 64 MiB，上传为每项 16 MiB，均校验 SHA256。数值包括连接建立，不能视为长期带宽承诺。Mb/s 为兆比特每秒。

| 模式 | 下载 Mb/s | 上传 Mb/s | UDP 1000 字节 echo |
|---|---:|---:|---|
| 普通 H3 | 233.10 | 10.46 | 20/20 |
| 普通 H2 | 191.65 | 11.47 | 20/20 |
| 严格 H3 | 192.08 | 41.22 | 20/20 |
| 严格 H2 | 191.64 | 43.11 | 20/20 |

这些上传差异来自不同时间的实测，不能据此认定 ECH 提升了上传速度。80 个 UDP 样本未丢失，仅说明此次小样本 echo 成功。H2 的 echo 依赖 TCP 重传，因此不等于底层没有丢包。

H3 人工弱网测试为本地应用中继对上下行 UDP 包独立随机丢弃，下载 8 MiB 校验：

| 人工条件 | 时间 | 有效下载 Mb/s | SHA256 |
|---|---:|---:|---|
| 1% 丢包 | 34.73 秒 | 1.93 | 一致 |
| 3% 丢包 | 55.21 秒 | 1.22 | 一致 |
| 5% 丢包 | 74.61 秒 | 0.90 | 一致 |
| 3% 丢包 + 单向增加 25 ms | 83.61 秒 | 0.80 | 一致 |
| 1200 字节 UDP 载荷限制，修复后 | 1.25 秒 | 53.92 | 一致 |

当前上游 CUBIC 在这些丢包条件下速度显著下降。下一阶段的性能工作应围绕实际链路损失和拥塞控制进行，不能用加密算法更换来解释或解决该问题。本版没有测量拥塞造成的实际丢包率、突发丢包、蜂窝切换或公网长期断线率。

```text
4d59a668f2f0c01a233ef7a47179dc898017fa90ef2a412dedbc1fc5cab0b8b1
```

四种组合同时下载 64 MiB 夹具，并取得完整 MP4 及起始/中部各 64 KiB 的 206 Range 响应。Range 内容与已经校验的完整文件对应片段逐字节一致。重测中 MP4 传输约 1.09–2.39 秒、34.2–75.0 Mb/s；Range 细节和并发下载时间见 JSON。未测量真实播放器首帧或卡顿率，也未测试第三方流媒体平台的地区策略。
