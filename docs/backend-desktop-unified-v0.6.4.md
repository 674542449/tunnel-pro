# 后台与 EXE 统一发布 v0.6.4

## 本次改动

此前后台 v0.5.7、客户端 v0.6.3，网站缓存标记仍为 0.5.4。现在产品共用 VERSION，生成两端 Go 常量、页面版本和后台资源缓存参数。网络协议内核继续为 v0.4.0。

构建和打包入口先检查两端版本。测试脚本默认从 VERSION 读取目标版本。统一打包复用桌面完整验收流程，不再提供独立版本的桌面重打包分支。新增上线检查：正式站、测试站、下载信息、HTTPS 实际文件 SHA256 和已验收 EXE 必须对应。

## 验证

- Go 全部包测试、go vet 和独立桌面模块测试通过。
- 客户端交互 47 项、Wails runtime 8 项、真实 EXE 隔离验收 21 项通过。
- 后台 DOM 23 项、购买流程 14 项、管理旅程 9 项通过。
- 版本源与发布门禁 7 组自动测试通过，覆盖版本漂移、缺失标记、保留内核版本、旧后台、旧下载版本、被替换的下载文件和未验收 EXE。
- 实际调用打包入口传入不同后台/桌面版本，被拒绝且未生成混合包。
- 新 EXE 使用测试账号完成连接、8 MiB 下载逐字节比对、HTTP CONNECT 和 SOCKS5 下载。没有打开 GUI 或修改本机系统代理，没有真实支付。

## 上线记录与维护

后台部署记录：`admin-alignment-deployment-v0.6.4.json`。EXE 验收记录：`admin-desktop-acceptance-v0.6.4.json`。公网最终结果以 `unified-release-v0.6.4.json` 为准，该文件仅在两站与下载包都通过检查后生成。

后续修改按 [统一发布规范](UNIFIED-RELEASE.md) 同时验收后台接口与 Windows 调用。统一版本不能代替功能测试。用户已经运行的旧 EXE 不会被自动替换，需下载更新并退出旧进程。
