# 管理后台 v0.4.1 修复与验收

本页保留 v0.4.1 的功能修复及验收记录。当前后台为 v0.4.2，界面、SVG 和最新构建说明见 [界面改版](ADMIN-DESIGN-v0.4.2.md)。

已部署到 https://test.xiaguamail.com/control/ 。本次升级管理服务；Windows 客户端、节点内核和账号接入版本继续为 v0.4.0，传输仍仅使用 HTTP/2。升级前后节点 PID 与重启计数一致，原有账号、节点、订单、公告和发布设置已核对保留。

## 修复与补充

| 问题 | 修复后的行为 |
|---|---|
| 节点、公告表单给 textarea/select 的只读 `type` 属性赋值，弹窗无法打开 | 只设置 input 的 type，节点、公告和设置表单可正常提交 |
| 后台缺少节点、套餐的完整编辑入口 | 可修改已启用或停用的节点、套餐；编辑节点保留其 ID、专用接入密钥与心跳信息 |
| 空订单等旧数据保存为 `null`，列表页报错 | 兼容旧 schema-1 快照，接口返回空数组；加载时不重写原数据文件 |
| 登录失效后停留在旧页面；请求先后返回可覆盖当前页面 | 401 清理界面并返回登录，丢弃过期页面响应；重置自己的密码后重新登录 |
| 小数金额被表单默认步长拒绝 | 支持 9.99 元、1.5 GiB 等数值，金额转换为整数分；限制非数字、范围和设备数 |
| 连续下载两个配置文件容易被浏览器拦截 | 单次下载配置 ZIP，包含 client.json、origin-ca.pem 和说明；原 JSON profile 接口继续兼容桌面客户端 |
| 订单缺少用户识别和取消操作 | 管理员可查看用户邮箱，用户或管理员可取消待核实订单；已开通订单不可取消，重复开通不重复增加权益 |
| 续期可能把仍有效的不限流量账号改成有限额度 | 有效的不限流量权限继续保留；已过期账号按新开通额度处理 |
| 注册与试用只能修改服务端文件后重启 | 后台可即时开关公开注册、调整试用时长（0–168 小时，0 为关闭）；保存于数据快照，优先于初始配置 |
| 公告与更新设置整组覆盖、校验不完整 | 分组和部分保存，保留其他设置；校验版本、HTTPS 地址及真实十六进制 SHA256 |
| 节点表单可能接受无效 ECH 或误粘贴的私钥 | 使用 Go TLS 离线检查 ECHConfigList；CA 栏只接受当前有效的 CA 证书，拒绝私钥和杂项内容 |
| 请求报错显示在弹窗后面、重复点击、列表难查找 | 弹窗内显示错误，保存期间锁定重复提交，网络超时提示核实结果；列表增加搜索和分页，手机窄屏保留退出入口 |

管理员可删除已停用套餐，以及已停用、无活动连接且至少 90 秒没有心跳的节点，需输入完整名称确认。历史订单保留套餐快照，历史计数和审计保留。删除节点前需停止对应节点服务。

敏感写操作在快照提交事务内再次检查会话和用户权限，防止被撤销的并发请求继续写入。配置 ZIP 只包含当前用户的访问凭据和公有 CA；节点接入配置仍含该节点的专用密钥，应只交给对应节点。

- Windows：Go race 回归、go vet、JavaScript 语法检查通过。

- 9 项线上 HTTPS 管理操作验收通过；合成测试节点和套餐已删除，测试账号已禁用，订单历史保留用于审计。
- 正式 H2 节点 8 项连接及安全检查通过；最终检查确认节点进程未重启、心跳正常、没有新增 panic、8443/UDP 没有监听。

## 构建与复测

只构建管理服务，不覆盖已有节点/客户端发布目录：

```powershell
.\tools\build-control.ps1
npm ci --prefix tools/admin-ui-test --ignore-scripts --no-audit --no-fund
node tools/test-admin-ui.mjs
python tools/package-control.py
```

需要 Go 1.27；本次 DOM 测试使用 Node.js 24.18.0。jsdom 是开发测试依赖，不属于管理服务运行依赖。测试数据与随机测试密钥写入 `.local/web-tests/`，不会进入公开包。

公开管理更新包：`dist/tunnelX-control-v0.4.1.zip`，含 Windows x64、Linux arm64/amd64 管理程序、安装脚本和许可证；完整源码：`dist/tunnelX-source-v0.4.1.zip`。校验清单单独保存在 `dist/SHA256-control-v0.4.1.json`，不修改旧发布清单。

Linux 解压管理包后，按现有管理 URL 执行 `sudo sh deploy/install-control.sh https://YOUR_DOMAIN/control`。生产升级前备份私有管理配置和数据；数据 schema 继续为 1。此次线上升级保留了仅 root 可访问的旧管理程序与快照，可用于回退。

## 仍使用原有方式的功能

订单由管理员人工核实开通，尚未接入在线收款。邮箱作为账号标识，没有邮箱验证或自动找回密码。更新由管理员填写下载地址和校验码，用户手动下载安装。本次没有加入自动升级、TUN、Android 或 iOS，也没有开展长期网络稳定性复测。
