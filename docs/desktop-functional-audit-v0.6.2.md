# Windows 客户端功能审计与修复 v0.6.2

检查日期：2026-10-03（北京时间）。基线为 v0.6.1，修复版本为 v0.6.2。

后续更正：v0.6.2 将非商业模式购买误判为不受支持，但后台实际支持人工核实订单。v0.6.3 已恢复此流程并补充对齐测试，详见 `backend-client-alignment-v0.5.7.md`；以下内容保留当时检查记录。

## 结论

发现并修复了设置草稿丢失、重复保存地址退出登录、选择节点和连接冲突、注册策略未完整加载、试用及购买入口不符合服务规则、退出账号写入失败后状态不一致等问题。修复后，43 项界面交互、8 项生产运行时脚本回归、20 项发布 EXE 验收通过；Go 全量测试、静态检查及桌面引擎 race 检查通过。

这里的“通过”指下表的自动化范围，不代表所有 Windows 版本和所有运营商环境都不存在问题。原生 EXE 验收使用隔离测试账户、独立目录和随机本机端口；未覆盖用户现有登录文件或代理设置。

## 本次修复明细

|问题|触发和原行为|修复后的行为|验证|
|---|---|---|---|
|服务地址草稿丢失|输入地址后离开输入框，每秒状态刷新将内容替换回旧地址|保留未保存草稿；保存失败也保留，保存成功后同步实际值|新增界面回归，旧版明确复现断言失败|
|重复保存地址退出账号|不修改地址，直接点保存，或粘贴带末尾 `/` 的同一地址|规范化地址，识别同一服务并保留会话；重启后会话仍存在|界面、引擎和发布 EXE 验证|
|带末尾 `/` 的合法服务地址无法使用|从浏览器复制地址后，保存或启动配置校验失败|接受末尾斜线和两端空格，仍拒绝凭据、查询参数、锚点和无效端口|新增引擎测试，旧版复现失败；EXE 验证同址保存和非法地址拒绝|
|选线保存期间可连接旧节点|节点偏好写入尚未完成时点连接|偏好写入结束前暂停连接入口，完成后连接新选择|延迟写入的界面回归|
|默认选线后台写入冲突|列表自动选中首个节点并后台保存，与用户的下一次选择竞争|自动选择只更新显示，用户明确选择才持久化|新增界面回归，确认没有隐式后台写入|
|邀请码规则尚未加载就开放注册|注册开关成功、商业设置请求失败时，缺少必填邀请码却出现注册入口|等待注册开关及邀请码策略都就绪；登录仍可用|失败场景及邀请码提交、拒绝后重试回归|
|试用和购买入口与服务端不符|商业服务展示无法开通的旧试用，或非商业服务展示不可执行的购买按钮|商业模式隐藏旧试用；非商业模式关闭购买，符合条件时可开通试用|两种模式分别回归|
|退出失败时显示已退出|登录凭据文件无法替换，内存却清空账号，重启可能又恢复旧会话|保留与磁盘一致的登录状态，明确报错，允许重试|通过目录占据凭据文件位置注入真实写入失败；旧版复现失败|
|退出后旧状态回调短暂恢复账户|退出与旧的状态轮询交错|先收完旧状态，再清理账户界面|生产 Wails 运行时脚本回归|

注册提交期间也禁止切换注册/登录模式或保存另一服务地址，避免不同操作同时改变登录目标。

## 尚未覆盖的验收

本轮没有真实 GUI 点击、窗口布局与缩放的视觉验收、系统浏览器弹出确认、文件保存对话框交互、真实商户扣款、真实 Steam 下载或长时间跨运营商测试。托盘与 WebView2 的交互仍需在真实桌面使用中观察。这些项目没有计入“已通过”。

自动安装更新、TUN 虚拟网卡、开机启动和跨节点自动切换目前未提供；它们不是本轮被修复的既有按钮功能。更新需正常退出旧程序，解压新版运行。
