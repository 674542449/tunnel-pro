# 支付图标来源

支付宝和微信图标路径取自 Simple Icons，并以本地 SVG symbol 随网站发布：

- [Alipay](https://github.com/simple-icons/simple-icons/blob/develop/icons/alipay.svg)
- [WeChat](https://github.com/simple-icons/simple-icons/blob/develop/icons/wechat.svg)
- [项目许可](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md)

图标用于标识对应支付方式，保留可见文字名称；不依赖外部图片请求。
