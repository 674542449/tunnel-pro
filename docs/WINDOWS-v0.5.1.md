# tunnelX Windows 桌面 v0.5.1

解压到一个可写的新目录，退出旧客户端后运行 `tunnelx-desktop.exe`。程序通过 `settings.json` 中的 HTTPS 管理地址登录，选择节点连接。系统代理只覆盖遵循 Windows 代理设置的应用。

本版修复：

- 登录会话确实失效（HTTP 401）时清除本地会话，回到登录入口；网络故障或需要 MFA 不会误清账号。
- 异常退出遗留代理增加恢复入口；启动和退出也尝试安全恢复。若原代理端口仍由其他实例使用，或其他软件已经修改代理配置，会保留现场并提示，不强行覆盖。
- 刷新同时更新节点、账户和订单；套餐展示金额/币种，流量加购显示当前有效周期。

关闭窗口会收起到托盘。“退出程序”会先尝试恢复代理；恢复失败会显示错误，不假称退出成功。

购买、MFA 和账号安全通过网站入口完成。桌面更新仍为手动下载，尚无自动升级安装、代码签名、自启动、TUN、安卓或 iPhone 版本。完整日志在程序数据目录 `logs`；没有集中上传到网站的日志系统。

网站、客户端和节点版本独立维护，当前客户端继续使用 H2/TLS/ECH 通道。网站控制器更新不会强制替换正在运行的桌面。
