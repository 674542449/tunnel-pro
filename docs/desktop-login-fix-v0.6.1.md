# Windows 登录与节点加载修复 v0.6.1

日期：2026-10-03（北京时间）。

## 已复现的问题

1. 登录前发出的 `Status` 查询尚未返回，登录成功后的 `refreshAll` 会复用这一次旧查询。旧结果仍为未登录，因此 `loadWorkspace` 提前返回。随后每秒轮询虽然显示已登录，却没有补发节点请求，线路页面会一直为空。
2. 界面首次读取本机状态失败，或原生桥接尚未准备好时，初始化中途结束。后续只有状态轮询，注册设置、账户和节点不会完整恢复。
3. 节点请求临时失败后必须手动刷新；错误恢复缺少自动重试。

测试通过实际 Wails IPC 脚本、生产运行时脚本、动态绑定和原生回调格式复现第一项，修复前节点数量断言为 `0`，期望为 `1`。Go 回调边界使用隔离测试数据；该测试不模拟真实 Windows 窗口绘制。

## 修复

- 登录成功后等待登录前的状态请求结束，再重新读取原生登录状态，清理旧账户视图并加载当前账户和节点。
- 状态轮询同时检查初始化/数据加载是否完成。遗漏或失败的读取自动重试；连续失败逐步延长重试间隔，最高 30 秒，成功后停止自动重复读取。
- 自动重试只涵盖读取操作，不重试登录、注册、购买、连接等变更操作。
- 桥接未初始化时显示明确中文提示；启动故障提示随恢复自动消失。
- 保留手动重新加载、会话失效返回登录、访客设置返回登录行为。

## 验收范围

- 7 项 Wails 运行时回归：真实脚本绑定、登录与旧轮询交错、迟到运行时、已保存会话、首次状态读取失败、节点请求失败退避及恢复、设置返回登录。
- 33 项界面交互回归；桌面引擎和原生外壳 Go 测试。
- 使用发布 EXE 的隔离测试账号验证实际登录、节点读取、重启恢复、HTTP/2 + ECH 连接和 8 MiB 下载逐字节校验；不修改用户系统代理。
- 主站和测试站只读核验：各有 1 个已启用、完成安装、近期上报的节点。未删除或重建节点。

前版的受控界面测试和无窗口 EXE 测试没有覆盖登录与状态回调交错，本次已补上。未进行真实 GUI 点击或视觉验收，也不能据此断言已复现用户机器上的每一种登录异常。

## 更新

从托盘退出旧客户端，再解压 v0.6.1 运行。网站和节点内核不需要升级。现有 AppData 登录与设置继续保留；如果原会话已过期，使用网站账号重新登录。
