# tunnelX Windows v0.5.0

管理平台：https://test.xiaguamail.com/control/ 。Windows 下载：https://test.xiaguamail.com/downloads/tunnelX-desktop-windows-x64-v0.5.0.zip 。当前为获邀技术试运营，测试付款不实际扣款。

1. 先从托盘退出旧客户端，释放本地 1080、8088 端口。
2. 解压到可写目录，启动 tunnelx-desktop.exe。需要 Windows x64 和 Microsoft WebView2 Runtime；程序尚未代码签名。
3. 使用原账号登录。已开启二次验证的账号可填写 6 位验证码或一次性恢复码；新账号按邀请注册，并验证邮箱。
4. 选择已授权节点，点击连接。系统代理只覆盖遵循系统代理设置的应用；自行直连的应用和 DNS 不会自动进入隧道。
5. “购买套餐”和“账号安全”会在默认浏览器打开管理平台。客户端保留 H2、严格 ECH 和原加密方式。
6. 关闭窗口会保留托盘连接。从托盘退出可停止连接并恢复原系统代理。

管理员首次登录后台需要亲自绑定验证器，保存恢复码。当前没有真实收款或邮件投递；试运营验证码邮件由管理员在后台查看。新测试付款仅适用于测试节点，原节点的既有账号权益仍兼容。

登录会话由当前 Windows 用户的 DPAPI 保护，不保存明文密码。文件包不含服务器、数据库或用户凭据。请不要将运行后生成的 DPAPI 状态和日志随公开安装包分发。

桌面客户端会持续记录连接、错误和 H2 探测。日志在解压目录的 logs 中，可能包含目标域名、地址和应用进程；不记录完整 URL、业务内容或 HTTP 凭据。

详细计费、退款、安全、备份与验收说明见 ADMIN-DESIGN-v0.5.0.md。当前版本已完成构建、接口及 DOM 验证，未执行图形渲染验收。
