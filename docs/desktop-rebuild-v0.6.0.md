# Windows 客户端体验重构与验收

日期：2026-10-03（北京时间）。从桌面 v0.5.1 重构为 v0.6.0；网站继续使用 v0.5.6，原有服务器传输内核未替换。

## 对原版的判断

原版是 Wails/WebView2 原生可视化客户端，按钮背后有真实登录、传输和代理实现。但它将账号、节点、连接、套餐及诊断堆在一个长页面中，缺少连接进度、取消操作、设置记忆与完整的购买确认，不能只因为“有窗口”就视为成熟的日常产品。

本轮将主要用户流程重构，并补齐对应原生接口；没有仅制作静态界面。

## 逐项变化

|范围|原来的体验/问题|v0.6.0 的实际行为|
|---|---|---|
|窗口与导航|480 像素窄窗口，功能纵向堆叠|连接、线路、订阅、设置与帮助四页；默认 1040×760，可调整大小；小屏交由 Windows 最大化适配|
|界面基础|文字按钮为主，状态层次弱|暖白与陶土色，内嵌 SVG 图标，明确空状态、加载与重试；键盘焦点、表单标签和减少动画支持|
|首次启动|必须有配置，数据在程序旁|默认官网地址；新用户数据存 Windows LocalAppData；已有便携数据原地兼容，不扫描其他安装目录|
|登录/注册|注册、邀请码、MFA 同时混在表单|注册遵循公开开关；MFA 按需展开；密码显隐、找回入口；失败有中文提示|
|登录损坏|DPAPI 无法读取时直接启动失败|启动只读并显示重新登录提示；真正写入前保留损坏文件，防止覆盖其他实例刚更新的文件|
|连接等待|网络调用持有状态锁，界面难以查看进度|展示恢复代理、获取配置、安全检查、账号验证和启动代理阶段；状态读取不等待网络|
|取消连接|无取消入口|可取消真实请求，关闭等待中的 TLS socket；处理取消与成功同时发生、IPC 迟到成功等边界|
|会话失效|仅依赖 token 比较处理旧请求|失效会话返回登录；清理只针对原连接，迟到的 401 不会断开替换后的新连接|
|节点端口|准入验证写死访问服务器 443|使用节点实际配置端口，支持仅开放自定义端口的节点|
|线路选择|平铺列表，选择不保存|名称搜索、地区/在线筛选、真实延迟探测；保存节点及系统代理偏好，重启保留|
|连接状态|本地隧道存在就显示已连接|独立显示节点 TLS/ECH 入口健康异常；60 秒检查一次、单次最多 5 秒；可断开重连|
|账户权益|简单文本|显示可用状态、到期、剩余流量、设备上限；无权益或待验证时提供行动入口|
|购买确认|点套餐立即创建订单|先确认金额、币种、周期与权益，再创建订单并打开网站；明确浏览器需用同一账号登录|
|重复购买|缺少完整客户端防重复处理|提交前读取订单并复用未过期待付款订单；请求结果不确定时不盲目重建；明确 4xx 拒绝后允许重试|
|价格快照|复用旧订单时可能显示当前套餐价|确认实际订单快照；服务端返回金额/周期/模式变化时，要求再次确认才打开付款网站|
|付款模式|提示容易与当前配置脱节|公开商业配置读取失败时阻止创建；复用订单按该订单自身的测试标记展示|
|返回客户端|主要依赖手动刷新|窗口重新获得焦点时同步权益；同时保留手动刷新与失败重试|
|代理恢复|已有底层恢复但入口分散|错误引导到设置页，提供恢复按钮；失败不假称退出成功；不覆盖其他活跃代理实例|
|更新|展示版本和 URL 文本|公开发布信息可在登录前检查；数值比较版本，旧版不提示降级；原生桥仅打开安全 HTTPS 下载链接|
|诊断支持|只能人工找日志文件|原生保存对话框导出脱敏摘要；取消不假称保存；不包含身份、令牌、访问目标或私有路径|
|启动故障|错误主要写到 stderr|GUI 启动失败提供原生错误提示；缺 WebView2 时显示微软安装指引；无窗口验收模式不弹窗|

选择另一条线路会保存为下次连接使用，不会偷偷打断当前下载。系统代理偏好也在下次连接生效。节点“在线”来自心跳；探测耗时不是吞吐测速，入口检查成功不表示所有目标网站都可达。

## 验收结果及其边界

|层次|结果|验证内容|
|---|---|---|
|自有 Go 代码|全量测试与 `go vet` 通过|基础客户端、控制器、节点、代理、诊断及集成回归|
|桌面引擎|21 个顶层测试通过，含 14 个本轮新增；`-race` 通过|真实本地 HTTP/TLS/ECH、状态响应、取消、健康失败恢复、401 归属、DPAPI、隔离注册表|
|原生外壳|8 个测试通过|目录兼容、默认启动、小屏判定、下载地址校验、Headless Host/Origin/CSRF|
|界面操作|[33 项通过](desktop-product-ui-v0.6.0.json)|DOM 与受控异步桥接：四页导航、账户失效、购买快照、重试、取消迟到连接、设置、更新和文本安全|
|实际 Windows EXE|[15 项通过](admin-desktop-acceptance-v0.6.0.json)|隔离测试账户、设置重启保留、严格 H2/ECH、8 MiB 文件逐字节一致、脱敏报告和原代理保持|
|发布包|[完整性验收](desktop-package-v0.6.0.json)|包内 EXE 与已验收二进制一致，ZIP 可读取，不含部署凭据或运行状态，依赖保持 H2|
|公开下载|[发布与 HTTPS 下载核验](admin-client-release-v0.6.0.json)|下载哈希、主站和测试站发布元数据、加密备份、原网络服务进程保持|

测试使用隔离目录、测试账号和临时回环下载服务，没有改动用户实际代理设置。临时服务完成验收后已停止；没有执行真实商户扣款或钱包转账。

本轮遵循既有无 GUI 验证方式，没有渲染真实窗口、截图检查像素、点击托盘或原生保存对话框。因此可以确认上述操作逻辑和真实网络调用通过，不能将其表述成已完成所有屏幕/DPI、无障碍读屏器和视觉效果的人工验收。

## 商业分发仍需完成的事项

这次已将日常使用流程落实为可运行的 Windows 图形客户端。正式大规模分发仍有独立工作：代码签名、安装器和卸载器、自动下载并验证/回滚升级、不同 Windows/DPI 的真实窗口验收、正式商户结算验收及长期网络测试。当前提供 ZIP 解压运行和手动更新，没有伪装这些能力为已完成。

TUN、开机自启动、跨节点自动故障切换、Android/iPhone 不属于本版实现。H3 按既有要求保持移除。

使用步骤见 [Windows v0.6.0 说明](WINDOWS-v0.6.0.md)。
