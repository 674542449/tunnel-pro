# tunnelX Windows 客户端 v0.6.3

适用于 Windows x64，使用 WebView2 显示原生窗口。解压后运行 `tunnelx-desktop.exe`，用网站账号登录；新用户使用默认服务地址，无需编写配置文件。首次使用时可在“设置与帮助”修改服务地址。

## 日常使用

1. **登录**：输入邮箱和密码；已开启二次验证的账号还需验证码或恢复码。注册入口遵循网站的开放设置；账号找回和安全设置在网站完成。
2. **选择线路**：进入“线路”按名称、地区或状态筛选。心跳在线和连接探测耗时是不同指标，探测耗时不是下载测速。
3. **连接**：回到“连接”，点击连接按钮。连接期间显示阶段，可以取消。启用系统代理后，遵循 Windows 代理设置的应用使用该连接；应用也可单独配置本地 SOCKS/HTTP 代理。
4. **购买和续费**：在“订阅”查看套餐、额度、到期和订单。确认金额及周期后创建订单，再用同一账号在网站付款；客户端登录不会自动登录浏览器。网站返回后刷新权益。测试订单明确标注，不代表真实扣款。
5. **断开与退出**：关闭窗口或“收起”会保留托盘和连接；“退出程序”先断开并恢复系统代理。恢复失败会给出提示，避免忽略遗留代理。

## v0.6.3 后台对齐

- 节点按当前账号对该节点的实际权限显示与连接，支持套餐指定节点和测试/正式范围。
- 套餐与购买确认显示节点范围；范围变化后需再次确认。
- 恢复后台支持的人工订单流程，明确提示管理员核实开通。
- 支持预发布版本和构建信息比较；每分钟同步后台账户、节点、套餐及订单变化。
- 保留此前登录、加载恢复、设置草稿与并发操作修复。

## 界面与功能

- 将原来的一页表单改为连接、线路、订阅、设置与帮助四个页面，使用 SVG 图标、明确的状态文字和键盘焦点。
- 记住所选线路和系统代理偏好，提供空列表、无权益、加载失败、登录失效及重试状态。
- 连接过程可取消；独立显示节点入口探测异常。探测只反映节点入口，不代表所有目标网站都可访问。
- 购买前确认金额和周期，复用仍有效的待付款订单，避免重复点击产生重复订单。
- 更新检查提供受限的 HTTPS 下载入口，仍由用户手动替换程序。
- 导出脱敏诊断摘要用于求助，不自动上传，不导出账号密码、令牌或访问目标。完整本地日志仍保留在数据目录。
- 本机登录状态损坏时保留损坏文件并提示重新登录。

## 设置和更新

新安装默认将设置、加密会话及日志保存到 `%LOCALAPPDATA%\tunnelXDesktop`。旧版本若在当前程序旁已有 `state` 目录，会继续使用该目录以兼容便携运行；不会自动从其他正在运行的客户端目录复制数据。`-state-dir` 和 `-config` 供隔离测试及明确指定配置使用。

更新前从托盘正常退出旧客户端，再解压新版本运行。新版与网站、节点分别维护版本；更新客户端无需重新部署节点。本版仍使用 HTTP/2 和严格 ECH。

## 当前边界

系统代理不会接管所有 Windows 应用，也不是 TUN 虚拟网卡。没有开机自启动、自动安装更新、跨节点自动切换、Android/iPhone 版本。发布文件尚无代码签名证书。若 Windows 缺少 WebView2，启动提示会给出微软官方安装指引。

本轮自动验收包括 DOM 操作、引擎并发与故障测试、原生 EXE 无窗口模式和实际 H2 下载；没有声称完成 GUI 截图、托盘点击、真实商户扣款或长期多运营商测试。
