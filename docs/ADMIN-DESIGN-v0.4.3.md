# tunnelX 管理后台 v0.4.3：节点一键接入

管理地址：https://test.xiaguamail.com/control/ 。刷新后台后进入「节点」，点击「添加节点」。

1. 填写名称、地区（选填）、服务器公网 IP、TCP 端口和域名。端口默认 8443，允许 1024–65535。
2. 保存后复制安装命令。命令含限时凭据，30 分钟内有效，请仅在对应节点服务器执行。
3. 使用 root 登录 Ubuntu / Debian，粘贴执行命令。脚本下载并校验内核，生成本机密钥与配置，配置证书和 systemd 服务，并自动回报后台。
4. 关闭命令窗口，节点列表每 10 秒自动刷新。安装成功后状态变为在线，客户端即可获取节点配置。

每个节点需要一个直接解析到其公网 IP 的域名，请关闭该记录的 CDN 代理。云安全组应允许入站 TCP 80、443（证书申请与续期）和所填节点端口；已有本机防火墙也需允许相应端口。脚本不能代替你配置云厂商的安全组。

本版使用独立 Caddy HTTPS 服务管理公开证书，因此节点端口使用 1024 以上端口，默认 8443。需要部署在 443 的场景，须另行设计证书签发与入口共用方式。

支持 Ubuntu / Debian 的 amd64、arm64，使用 apt 和 systemd。管理后台为 v0.4.3，节点仍使用经过验证的 v0.4.0 H2 内核；本次增加部署流程，没有升级现有节点内核。

## 安装过程与故障处理

- 已有节点可继续使用「手动添加」，填写原有 ECHConfigList 与 origin CA。
- 新节点以「待安装」状态登记，安装完成前不向用户展示、不分发用户授权。安装失败时后台显示失败阶段，详细原因在服务器终端查看。
- 命令过期或丢失时，点击「生成安装命令」。旧命令和旧节点接入密钥同时失效；在原服务器重新执行新命令，会保留该待安装节点已生成的内层密钥。
- 安装成功后凭据不能再下载配置或内核；为容忍网络超时，完成回报在原凭据到期前可以幂等重试。
- 端口被占用、域名未指向登记 IP、证书未签发或服务无法启动时，脚本会停止并报错。可修复对应条件后在有效期内重试。
- 安装命令需要访问后台 HTTPS；无需在网页填写 SSH 用户名或密码。

## 配置位置

每个节点使用独立目录与服务，避免覆盖已有部署。`NODE_ID` 是后台生成的 32 位标识：

| 内容 | 路径 / 服务 |
| --- | --- |
| 节点配置与私钥 | `/etc/tunnelx-nodes/NODE_ID/` |
| 节点内核与证书同步工具 | `/opt/tunnelx/nodes/NODE_ID/` |
| 心跳与累计流量状态 | `/var/lib/tunnelx-nodes/NODE_ID/` |
| 节点服务 | `tunnelx-node-NODE_ID.service` |
| 公开证书同步定时器 | `tunnelx-node-NODE_ID-cert.timer` |

可使用 `systemctl status tunnelx-node-NODE_ID.service` 和 `journalctl -u tunnelx-node-NODE_ID.service --no-pager` 查看状态。停止节点后在后台停用，等待最近心跳超过 90 秒、活动连接数为 0，才能删除节点记录。删除后台记录不卸载服务器上的服务或文件。

## 证书与凭据

ECH 私钥、内层证书私钥和本机备用令牌在节点本地生成，后台只接收公开 ECH 配置和 CA 证书。安装凭据使用随机 256 位值，后台仅存哈希。内核下载和安装脚本均校验 SHA256，下载地址与架构受限。

外层公开证书由 Caddy 申请、续期。已有匹配域名的有效 Caddy 证书会被复用；否则脚本添加独立站点配置并校验，保留原 Caddyfile 备份。每小时同步公开证书，内核在 TLS 握手时重新加载，不需重启节点。Caddy 自动 HTTPS 行为参见 [官方文档](https://caddyserver.com/docs/automatic-https)。

**内层证书目前有效期为 6 个月，origin CA 为 1 年，尚未加入自动轮换。** 到期前需安排内层证书更新；本次不能据此承诺长期无人维护。

## 验证范围

后台接口、限时凭据、权限隔离、重复回报和表单流程均有回归测试。完整 systemd 安装在 Ubuntu ARM64 的独立测试节点验证；Debian ARM64 运行相同管理测试，并验证脚本语法与配置生成。Debian chroot 不具有独立 systemd，不能把这项验证视为独立 Debian 主机的完整安装验收。未运行浏览器渲染。

本次 Ubuntu 安装复用了现有域名的有效公开证书，新建 Caddy 站点配置另在隔离目录校验，并检查 Caddy 服务账号读取权限；未重新向公开 CA 申请新域名证书。H2 连接验收通过服务器回环地址连接临时节点，未验证云厂商安全组对新端口的放行。

验收记录：[后台与表单](admin-dom-acceptance-v0.4.3.json)、[一键安装](admin-node-install-v0.4.3.json)、[H2 连接](admin-node-transport-v0.4.3.json)。Ubuntu 和 Debian 各通过 16 项管理测试，表单通过 23 项检查。

管理包中 `node-artifacts/` 为一键安装所需的稳定节点内核。自建后台时使用包内 `deploy/install-control.sh` 安装，该脚本会同时放置这些内核文件。缺少文件时后台会返回明确提示。
